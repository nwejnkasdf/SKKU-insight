본 파일은 SRS v0.3 §2 (Product Perspective ~ Assumptions and Dependencies)을 분할한 것이다. 다른 분할 파일: [`00-overview.md`](00-overview.md), [`02-functional-requirements.md`](02-functional-requirements.md), [`03-nonfunctional-requirements.md`](03-nonfunctional-requirements.md), [`04-data-model.md`](04-data-model.md), [`05-architecture-and-flows.md`](05-architecture-and-flows.md).

## 2.1 Product Perspective

`SKKU InSight`는 사용자의 관심 상태를 기반으로 CS/AI 기술 동향을 선제적으로 제공하는 Windows 데스크톱 애플리케이션이다. 사용자는 검색어를 매번 입력하지 않아도, 시스템이 사용자의 장기/단기 관심을 추론하고 사용자별 관심 토픽에 맞는 자료를 수집하여 대시보드에 제공한다.

시스템은 다음 하위 시스템으로 구성된다.

- Windows 데스크톱 클라이언트
- 사용자 계정 및 인증 시스템
- 개인정보 및 개인화 동의 관리 시스템
- 관심 상태 추론 시스템
- 토픽 매핑 및 사용자별 동적 리프 토픽 관리 시스템
- 소스 수집 에이전트
- DoRA 파인튜닝된 `A.x 4.0 light` 기반 낚시성 탐지 시스템
- 추천 생성 및 랭킹 시스템
- 별도 관리자 웹 콘솔
- 클라우드 데이터베이스

### 2.1.1 System Interfaces

시스템은 다음 외부 시스템 또는 데이터와 연동한다.

| 외부 대상 | 연동 목적 |
|---|---|
| 이메일 계정 인증 시스템 | 일반 이메일 및 비밀번호 기반 사용자 회원가입과 로그인 인증 |
| CSO 데이터 | 상위 토픽 좌표계 제공 |
| 학술지/논문 데이터 소스 | 학술 동향 자료 수집 |
| 빅테크 공식 채널 | 공식 발표, 연구 블로그, 릴리즈 노트, 공식 문서 수집 |
| 테크 뉴스 소스 | 최신 기술 뉴스와 기사 수집 |
| 낚시성 탐지 모듈 | 뉴스/기사성 2차 문서 품질 필터링 |
| 관리자 웹 콘솔 | 운영자 인증, 수집 상태 조회, 실패 작업 재실행 요청 |

### 2.1.2 User Interfaces

사용자용 Windows 앱은 다음 핵심 화면을 제공한다.

- 온보딩 화면
- 대시보드 화면
- 토픽 상세 화면
- 문서 상세 화면
- 설정/피드백 화면

관리자용 화면은 일반 사용자용 Windows 앱에 포함하지 않고, 운영 모니터링 목적의 별도 내부 웹 콘솔로 제공된다.

- 관리자 로그인 화면
- 에이전트 수집 상태 화면
- 실패 로그 화면
- 낚시성 판별 통계 화면
- 토픽 연결 오류 화면
- 재실행 요청 화면

### 2.1.3 Hardware Interfaces

1차 대상 하드웨어는 Windows 데스크톱 또는 노트북 PC이다.

| 항목 | 최소 요구사항 |
|---|---|
| CPU | 일반적인 Windows 10 이상 구동 가능 CPU |
| RAM | 8GB 이상 권장 |
| Storage | 앱 설치 및 로컬 캐시 저장을 위한 1GB 이상 여유 공간 |
| Network | 인터넷 연결 필요 |

### 2.1.4 Software Interfaces

| 항목 | 요구사항 |
|---|---|
| 운영체제 | Windows 10 이상 |
| 서버 | 클라우드 기반 API 서버 |
| 데이터베이스 | 사용자, 관심 상태, 문서, 토픽, 피드백 저장용 서버 DB |
| 모델 | DoRA 파인튜닝된 `A.x 4.0 light` 기반 낚시성 탐지 모듈 및 LLM/에이전트 기반 토픽 처리 구성요소 |

### 2.1.5 Memory Constraints

- Windows 앱은 일반적인 학습/연구용 노트북에서 구동 가능해야 한다.
- 앱 로컬 캐시는 기본 1GB를 초과하지 않아야 한다.
- 대량 문서 원문은 클라이언트에 영구 저장하지 않고 서버 또는 원문 링크를 통해 접근한다.
- 백그라운드 수집과 모델 추론은 클라이언트가 아니라 서버 측에서 수행한다.

### 2.1.6 Operations

시스템은 다음 운영 작업을 수행한다.

- 사용자별 관심 토픽에 맞춘 일 1회 기술 동향 자료 수집
- 수집 자료의 상위 CSO 토픽 및 사용자별 동적 리프 토픽 연결
- 뉴스/기사성 2차 문서 낚시성 탐지
- 사용자별 추천 후보 생성 및 10개 추천 대시보드 구성
- 앱 실행 시 최신 대시보드 제공
- 수집 실패 및 토픽 연결 오류 기록
- 관리자 웹 콘솔의 재실행 요청 처리
- 낚시성 탐지 결과 통계 집계

## 2.2 Product Functions

`SKKU InSight`는 다음 주요 기능을 제공한다.

1. 일반 이메일 및 비밀번호 기반 사용자 계정 생성과 로그인
2. 개인정보 및 개인화 데이터 수집 동의
3. 온보딩 관심 분야 선택
4. CSO 상위 토픽 매핑
5. 사용자별 에이전트 기반 동적 리프 토픽 연결
6. 사용자 행동 로그 수집
7. 장기/단기 관심 상태 추론
8. 사용자별 관심 토픽에 맞춘 학술지/논문, 빅테크 공식 채널, 테크 뉴스 수집
9. DoRA 파인튜닝된 낚시성 탐지 모듈 기반 2차 문서 필터링
10. `core`, `adjacent`, `discovery` 슬롯 기반 10개 추천 대시보드 제공
11. 토픽 상세 정보 제공
12. 문서 상세, 섹션형 생성 요약, 짧은 토픽 근거 제공
13. 저장, 숨김, 관심 없음 피드백 제공
14. 개인정보 수집 동의 및 설정 관리
15. 계정 및 개인화 데이터 삭제 요청
16. 별도 관리자 웹 콘솔 기반 권한 분리 및 운영 모니터링

| 사용자 클래스 | 설명 | 주요 니즈 |
|---|---|---|
| 이공계 학생 | CS/AI 관련 학습 및 프로젝트를 수행하는 학생 | 최신 기술 흐름 파악, 학습 자료 발견 |
| 연구자 | 특정 연구 주제를 지속적으로 추적하는 사용자 | 논문, 공식 자료, 연구 동향 추적 |
| 교수 | 강의, 연구, 지도에 필요한 기술 동향을 확인하는 사용자 | 신뢰도 높은 자료와 분야별 흐름 파악 |
| 관리자 | 서비스 운영 상태를 확인하는 운영 담당자 | 수집 실패, 토픽 오류, 필터링 통계 확인 |

## 2.4 Operating Environment

사용자는 인터넷에 연결된 Windows 10 이상 PC에서 데스크톱 앱을 실행한다. 관심 상태, 피드백, 설정, 추천 결과는 클라우드 서버와 동기화된다.

관리자는 별도 내부 웹 콘솔에서 관리자 권한으로 로그인한 뒤 수집 에이전트와 필터링 시스템의 동작 상태를 확인한다.

## 2.5 Design and Implementation Constraints

- 1차 클라이언트는 Windows 데스크톱 앱으로 제한한다.
- 초기 기술 도메인은 CS/AI로 제한한다.
- 개인화 데이터 수집 동의는 필수이며, 동의하지 않으면 회원가입 또는 초기 설정을 완료할 수 없다.
- 사용자가 필수 개인화 동의를 철회하면 계정은 유지하되 추천 대시보드와 개인화 기능은 중단하고 재동의, 계정 삭제, 설정 화면만 제공한다.
- 낚시성 탐지 점수는 사용자에게 직접 노출하지 않는다.
- 추천 슬롯은 초기 버전에서 총 10개 카드로 구성한다.
- 추천 슬롯 비율은 후보가 충분한 경우 `core:adjacent:discovery = 5:3:2`를 목표로 한다.
- 학술지/논문, 빅테크 공식 채널, 테크 뉴스는 추천 후보에서 동등하게 고려하되, 뉴스/기사성 문서는 낚시성 탐지 모듈을 통과해야 한다.
- 관리자 웹 콘솔은 수동 큐레이션보다 운영 모니터링에 초점을 둔다.

## 2.6 User Documentation

사용자에게 다음 문서를 제공한다.

- 앱 시작 및 계정 생성 안내
- 개인정보 및 개인화 데이터 수집 동의 안내
- 온보딩 관심 분야 선택 안내
- 추천 카드와 토픽 상세 화면 안내
- 저장, 숨김, 관심 없음 피드백 사용 안내
- 계정 및 개인화 데이터 삭제 안내

관리자에게 다음 문서를 제공한다.

- 관리자 로그인 및 권한 안내
- 수집 에이전트 상태 확인 안내
- 실패 로그 확인 및 재실행 요청 안내
- 낚시성 탐지 통계 확인 안내
- 토픽 연결 오류 확인 안내

## 2.7 Assumptions and Dependencies

- 사용자는 일반 이메일과 비밀번호를 통해 가입할 수 있다.
- 사용자는 개인정보 및 개인화 데이터 수집에 동의해야 서비스를 사용할 수 있다.
- 사용자는 온보딩에서 최소 1개 이상의 관심 분야를 선택한다.
- CSO 데이터는 초기 CS/AI 상위 토픽 매핑에 사용할 수 있다.
- 외부 소스는 네트워크를 통해 접근 가능하다.
- 낚시성 탐지 모듈은 뉴스/기사성 2차 문서에 대해 판별 결과를 제공할 수 있다.
- `A.x 4.0 light` 기반 낚시성 탐지 모듈은 별도 validation 기준 accuracy, recall, AUROC, F1이 모두 98%대인 것으로 가정한다.
- 일 1회 수집 주기는 초기 서비스에서 충분한 최신성을 제공한다고 가정한다.
